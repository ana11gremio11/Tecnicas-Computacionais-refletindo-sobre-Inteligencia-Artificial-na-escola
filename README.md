
## O que o projeto faz

- Tela inicial com botão **Iniciar**
- Perguntas com alternativas
- Afirmações aleatórias a cada escolha
- Nome aleatório no lugar de "você"
- Caminhos diferentes (fluxograma com `proxima`)
- História final personalizada
- Botão **Jogar novamente**

## Como rodar

1. Abra a pasta do projeto no VS Code
2. Clique com o botão direito em `index.html`
3. Escolha **Open with Live Server** ou **Live Preview**

> Importante: o projeto usa módulos ES6 (`type="module"`).  
> Não abra o arquivo HTML direto no navegador. Use o Live Server.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES Modules)

## Publicar no GitHub Pages

1. Crie um repositório no GitHub
2. Envie os arquivos do projeto
3. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`
4. Acesse o link gerado
